# Digest PDFs

GitHub truncates a directory listing at 1,000 files. Digests live in subfolders; filenames are unchanged.

| Folder | Contents |
|---|---|
| `significant/` | Cases with `significance: significant` (`SCJ-NNN_S_<slug>.pdf`) |
| `001-1000/` | Other digests, case ids SCJ-001 … SCJ-1000 |
| `1001-2000/` | Other digests, case ids SCJ-1001 … SCJ-2000 |

Further ranges (`2001-3000`, …) are added as ids cross each thousand.
